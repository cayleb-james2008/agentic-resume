Independent engineering project · October 13, 2026

Ergon

Windows employee-assistant installer. Outis taskbar management. Linux support desk.

Built around the employee

Each employee gets an OpenClaw workspace. Data kept through upgrades. A light assistant with bounded expert consultation. Outis: a neutral taskbar for setup, support requests and connection status.

Screen-based remote maintenance

Reviewed tickets. Durable storage, immutable retries, fenced repair leases. One maintenance worker per Windows device: PowerShell, diagnostics, power/reconnect tools, a real remote Desktop canvas. PNG screen results for inspection, mouse and keyboard input. New actions void old visual evidence.

Automatic connector builds

A ticket queues a builder. It reads public API docs, writes a declarative REST manifest, tests the trusted template. Employees grant exact read/write operations. Credentials go in through protected Windows setup. Activation and rollback need a local Gateway reload and tool-registry check.

Phone and workflow integration

Reviewed onboarding turns an approved work example into a versioned workflow. Separate activation and rollback. Hosted voice needs exact operator approval and shares the model-call budget. Contacts and provider settings stay in protected local config.

Verification

Source tests: device isolation, lease expiry, connector grants, receipt retries, interrupted installs, Gateway contracts. Real browser fixture: screenshots, pointer and keyboard input, reconnect, image delivery. Native helpers compile against pinned .NET Framework references.

Pilot acceptance

Native Windows installation, real screen control, reboot reconnect, a live connector account call, an automatic Work repair, exact model calls, mobile access and an approved voice call: still need live checks. Not a completed deployment.

Source access

Implementation and enrollment packages: private. This page: engineering scope and verification limits. No employee information. No access credentials.

Evidence
