Public codebase · multi-agent coding dashboard · Rust + Tauri

dotz

A local-first desktop control surface for coordinating coding agents through a live workflow graph.

  • Rust / axum
  • Tauri desktop shell
  • Windows-first
  • Public repository

What it does

The public README describes one task being split across coding-agent roles and tracked in a live workflow graph. A Rust/axum service and Tauri shell bring the agent runtime and desktop interface together; the repository also documents sandboxed previews and local memory.

How to try it

Start with the README, screenshots, and dated status notes. For the headless development path, follow its setup steps (Rust, Node.js, and Tauri platform prerequisites), run cargo run -p dotz-core --bin serve, then open http://127.0.0.1:4317. The native desktop path is Windows-first.

Live model prompts require a provider credential configured as described in the README. The agent can edit files and run terminal commands: test it in a disposable workspace and review permissions before use.
