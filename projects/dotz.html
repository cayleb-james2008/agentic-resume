dotz

An agent desktop with explicit local routing, supervised tools and platform-specific process cleanup.

What it does

dotz connects the desktop interface to an agent core, provider selection and supervised tool execution. Lifecycle policy keeps child processes and session shutdown visible.

Local routing

Selecting a local provider now keeps failures on that route, with an actionable status. Cleanup retries retain session state until child processes have actually closed.
