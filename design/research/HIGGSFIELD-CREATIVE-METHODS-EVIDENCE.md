## 13. Best-practice method summary (evidence-backed, no redesign)

Methods **explicitly taught** by official Higgsfield docs/blogs for high-end brand/portfolio-grade motion assets:

1. **Lock identity first** — Soul ID (20–80 strong photos) or AI Influencer → portrait batch → Soul ID; reuse via Character panel / Elements `@` tags.  
2. **Lock look as stills** — Soul Cinema (+ Soul HEX) for cinematic keyframes; avoid simultaneous prompt+reference on Soul Cinema.  
3. **Short directed hero motion** — DoP preset animation of a sharp keyframe (3–5s) for branded promo-style motion.  
4. **Longer cinematic scenes** — Cinema Studio 4.0 Director’s Panel (genre → camera/lens/aperture → tempo → emotion → scene prompt) + Elements; prefer Single Shot when identity continuity across cuts is critical.  
5. **Iterate cheaply** — Prototype 720p / no audio / Fast-Turbo; then final high-res + audio (enterprise AI-models tip).  
6. **Multi-model factory** — Canvas templates or API pipeline Soul 2 → Soul Cinema → video model; download within retention window to own storage.  
7. **Ads / UGC variants** — Marketing Studio templates + Brand Kit + trained Soul ID spokesperson (≤15s).  

All of the above are **capabilities/workflows**; none are recommendations to redesign a personal portfolio site.
