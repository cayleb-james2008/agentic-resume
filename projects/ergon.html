Independent engineering project · October 13, 2026

Ergon

A Windows employee-assistant installer, with Outis taskbar management and a Linux support desk.

Built around the employee

Ergon gives each employee an OpenClaw workspace, preserves their data through upgrades, and configures a lightweight assistant with bounded expert consultation. Outis provides a neutral taskbar interface for setup, support requests and connection status.

Reviewed remote support

A request is previewed before sending. Device-scoped access, immutable retries, durable SQLite storage and fenced repair leases keep delivery and ownership explicit. Connection status comes from a fresh authenticated remote-manager observation. A repair outcome includes an operator receipt.

Phone and workflow integration

Reviewed onboarding turns an approved work example into a versioned assistant workflow, with separate activation and rollback. Hosted voice workflows require exact operator approval and share a budget with model calls. Contacts and provider settings stay in protected local configuration.

Verification

Source tests cover support persistence, scoped access, lease expiry, minimized notifications, and uncertain delivery retries. The Outis dashboard was checked in a browser, and its Windows helper compiles against pinned .NET Framework references.

Pilot acceptance

Native Windows installation, reboot reconnection, an automatic Work repair, exact model calls, mobile access and an approved voice call still require live checks. The candidate is not described as a completed deployment.

Source access

The implementation and enrollment packages are private. This page publishes the engineering scope and verification boundaries without employee information or access credentials.

Evidence

Private source. Windows pilot acceptance is tracked separately from compilation and source tests.
