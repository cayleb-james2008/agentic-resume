# Open-source cinema pipeline (Higgsfield-inspired methods)
Date: 2026-09-22 · **No paid Higgsfield.** Methods only.

## Execution stack (Cayleb lock)
| Stage | Tool |
| --- | --- |
| Stills / brand mark / hero frames | **ChatGPT image gen** |
| Motion / hero reel | **Veo** (Google) |
| Finish | ffmpeg on box (mute loop, poster extract) |
| Site craft | Swiss type/space + GSAP one signature; poster + optional muted MP4 |

## Method map
| Method | Our execution |
| --- | --- |
| Hero Frame First | Approve bandit still in ChatGPT before any Veo job |
| DP-style rig | Prompt sensor/lens/focal/aperture/light in ChatGPT + Veo |
| Shot list | 5–8 beats; stills first, then Veo per beat or one hero |
| Cinema vocabulary | Optics + camera moves, not mood-only adjectives |
| Look lock | One palette + bandit mark description reused every gen |
| Character consistency | Same mark prompt + reference still into ChatGPT / Veo |
| Grid / storyboard | 4–9 ChatGPT variants → pick hero → animate |
| Inspect | Hands/faces/text/geometry before site wire |
| Finish | Mute loop MP4 + poster; `prefers-reduced-motion` → poster |

## Brand
Clean **dark digital bandit** — premium, sharp, sparse. Not nomad, not CRT carnival, not sticker grunge.
