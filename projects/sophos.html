at a glance

What Sophos is

Sophos brings Prime Intellect's open-source Prime Agent to Windows through a graphical desktop app. It adds a Tauri v2 and Rust shell, React views for sessions and agents, packaging, and reliability layers around the upstream agent service. Prime Intellect created the agent service and its bridge; Sophos pins their public v0.7.0 source and includes the upstream MIT notice.

The app is Windows-only and every version before 1.0 is a beta. The desktop shell and the interface are this project's work. The repository's quick start covers installing the signed package, adding a provider, and starting a session.

What was verified, and when

The source passed 1,224 Vitest tests across 147 files, 82 Node tests, and eight Rust tests for the saved session layer. The bridge boundary suite passes nine checks. Profile tool, skill and safety choices remain descriptive; they do not grant permissions. The change merged October 13 (commit 33559fc). For the Windows baseline (source commit 48d6cbd), the exact-head run passed 1,126 frontend tests, seven native containment checks, staged and standalone lifecycle checks at 50/50 each, and eight automated interface suites. Three background keyboard subchecks were skipped because a background WebView2 does not reliably receive synthetic keyboard input; unit coverage remains.

The signed updater package is a separate publication record: it passed 22 checks with 0 failures and one informational result, and was installed in a fresh profile; its installer hash is recorded in the repository. A fresh-profile smoke of the public installer passed 7/7, though one entry is an explicit no-op placeholder and only six perform real assertions. The native Windows interface suites passed 8/8. The releases page currently lists v0.6.0 as the latest tagged release while the updater feed announces v0.7.2; these are different records, and the package is not proven to match this source tree.

what is not verified

  • Installing the source build from scratch and getting live AI answers remain unverified.
  • Current-source installer acceptance and live provider inference remain unverified.
  • The signed updater package is not proven to contain this source revision.
  • Every release before 1.0 is a beta; the repository warns that features may change and bugs may exist.
  • The interface suites used a test connection, not live AI calls or answers.
  • The Windows test run covers hosted Windows, not every Windows version.
  • The 7/7 public-installer smoke includes one explicit no-op placeholder; only six of its entries perform real assertions.
