> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the water-story homepage with the approved Lumora-layout page:
- loader, liquid-reveal hero, About, band, Ergon team graph, Work cards, What I do, stats;
- the official résumé, footer, menu, request modal and Ask my agent.

Subpages and the share card are reskinned to match. The work merges to `main` and goes live once everything passes.

**Architecture:**
- Python templates in `scripts/home/templates/` render every section from `site/content.json`; the résumé comes from `resume/resume-content.json`.
- Plain CSS per section in `site/css/`.
- Vanilla ES modules in `site/js/home/`. Each exports pure, node-tested helpers plus a `mount(el, ctx)` that touches the DOM.
- `site/js/main.js` boots Lenis on the shared ticker, then mounts each block.

**Reference implementation:** the approved mockup in `/tmp/claude-0/-home-user-agentic-resume/c4ba6964-a271-5dc4-987d-3b73e4601978/scratchpad/lumora/`. **Tech Stack:** Python 3 templates, vanilla ES modules, vendored Lenis 1.3.26, Pillow (share card), node:test, Python unittest, Playwright with Chromium at `/opt/pw-browsers` (hero layers and QA only).

## Global Constraints

- **Nothing third-party at runtime.** Lenis comes from `vendor/lenis-1.3.26` through the import map, which holds `lenis` only. Fonts load from `assets/fonts/`. Nothing loads from a CDN.
- **No `@keyframes` anywhere.** Motion is CSS transitions plus small rAF loops on `engine/ticker.js`.
- **Hiding is guarded.**
  - Any rule whose body sets `opacity: 0` or `visibility: hidden` has every selector starting with `.js:not(.reveal-failsafe)`.
  - Closed overlays use the `hidden` attribute, with `[hidden]{display:none!important}` in `base.css`.
  - The 4s head failsafe stays, and `window.__homeBooted = true` stays the last statement of `boot()`, after every `mount(`.
- **`tokens.css` raw values** (the 31 pinned in `home-shell`, plus `ink-alpha-35`, `white-alpha-40` and `cyan-700`) stay verbatim. Add raw tokens freely, and re-point the tier-2 roles.
  - New raw tokens: `--raw-color-cool-50: #f0f2f2`, `--raw-color-cool-100: #e1e5e6`, `--raw-color-cool-150: #e3e7e8`, `--raw-color-cool-300: #cdd2d4`, `--raw-color-term-900: #0f1519`, `--raw-color-term-200: #cfdcde`, `--raw-color-term-400: #8a9da2`, `--raw-color-ok-300: #7ee2b8`, `--raw-color-warn-400: #f2a93b`.
  - Fonts: `--font-sans` and `--font-display` are `"Onest", ui-sans-serif, system-ui, sans-serif`. `--font-mono` is `"JetBrains Mono", ui-monospace, Menlo, Consolas, monospace`.
- **Copy rules.**
  - Every visible string lives in `site/content.json`, except the résumé half, which comes from `resume-content.json`.
  - Straight apostrophes throughout.
  - Every digit run in `content.json` appears in `resume-content.json`, except `$100`.
  - No `hedge fund|returns?|profit|revenue|clients?|customers?`.
  - No hours/pay/people takes, no model names, no racing words (so not "driver"), no "illustration".
  - "pilot" appears in the guide only as "Windows pilot, live checks pending".
  - The jargon ban covers all `content.json` copy except the keys `builtWith`, `terminal` and `cmd`.
- **Layout-reference names** (`kimi|antonelli|mercedes|grid0?1|getlayers|lumora`) never appear in `site/` or on served pages.
- **URLs.** Every local URL is relative, with no leading `/`. Every `href` and `src` resolves (`check-release.py`).
- **Images.** The homepage's `<img>`s come only from `assets/hero/` and `assets/work/`, and each is listed in `assets/IMAGES.json`. None shows a person.
- **Untouched:** `resume/*`, the PDFs, the `.txt`/`.md` exports, the project page bodies and the lab receipts.

## Review Focus

1. **Arriving on a deep link** (`index.html#experience` from a project page). Expected: no loader, the header shows, the hero reveals still finish, and the page lands on the section. Covered by `shouldPlay` (Task 2) and QA (Task 9).
2. **Switching team mid-ticket, or rotating or resizing mid-animation.** Expected: wires are re-measured, packets in flight resolve, the ticket button comes back, and no card stays amber. Covered by the `graph.js` helpers (Task 2), `ergon.js` (Task 6) and QA.
3. **Menu → Contact → modal.** Expected: the menu closes, the modal opens, scroll stays locked exactly while an overlay is open, focus is trapped and returned, and Escape closes the top overlay. Covered by `createScrollLock` (Task 2) and QA.
4. **Unusual input in the request modal.** Expected: an empty or malformed email gets a fix-it message, any characters reach the mail draft intact, and a denied clipboard falls back to selecting text. Covered by `composeMail` and `validate` (Task 2).
5. **No JS, reduced motion, or a failed image or font.** Expected: every word stays readable, the carousel shows item one, the graph is a static team with the log's last lines, and nothing waits at `opacity:0`. Covered by `home-sections` (Task 4) and QA.

### Task 2: Pure helpers

**Files:**
- Create: `site/js/home/{grid,loader,liquid,reveal,carousel,clock,count,graph,overlays,mail}.js` (pure parts only; `mount` comes in Task 6) and `tests/home-math.test.js`.

**Interfaces (exports):**
- `grid.js`: `rootFontSize(width) → number | null`. Null at ≤1920; otherwise `16 − 16·(((1920−w)/1920)·100·0.6666)/100`.
- `loader.js`:
  - `easeInOutCubic(t)`;
  - `counterLabel(p) → '000'…'100'`;
  - `shouldPlay({ reduced, hash, seen }) → boolean`, true only when not reduced, the hash is empty and the loader hasn't been seen;
  - `FILL_MS = 1300`.
- `liquid.js`:
  - `BRUSH_RADIUS = 143`, `DECAY = 0.016`, `FADE_FRAMES = 120`;
  - `trailPoints(last, next, radius) → [{x,y}]`. With no `last` it returns `[next]`. Otherwise it interpolates with step `max(radius·0.3, 1)`, `n = min(ceil(dist/step), 60)`, and ends exactly at `next`.
  - `fadeFor(drawing, idle) → drawing ? DECAY : min(DECAY + idle·0.004, 0.5)`;
  - `coverRect(iw, ih, w, h) → {x, y, w, h}`, centred so it fills.
- `reveal.js`: `lineIndexes(tops, tolerance = 4) → number[]` (`[0,0,40,40,80] → [0,0,1,1,2]`).
- `carousel.js`: `step(i, delta, n) → (i + delta + n) % n`.
- `clock.js`: `formatClock(date, timeZone = 'America/New_York') → { time: '4:22pm', date: '15 October, 2026' }`.
- `count.js`:
  - `countProgress(top, height, vh) → clamp((vh − top) / (vh/2 + height/2), 0, 1)`;
  - `splitFigure('3,300+') → { prefix: '', value: 3300, suffix: '+', comma: true }`;
  - `formatCount(n, comma)`.
- `graph.js`:
  - `ladderStop(n) → n % 7 === 0 ? 2 : n % 3 === 0 ? 1 : 0`;
  - `wirePath(mode, hub, card, mark) → string`. `'cols'` is a cubic from the hub's bottom centre to the card's top centre. `'rows'` is a bus `M sx,sy V ey−10 Q sx,ey sx+10,ey H ex`, from the mark's centre x to the card's left edge.
  - `nextTeam(names, current, delta)`.
- `overlays.js`: `createScrollLock({ stop, start }) → { lock(), unlock(), get count() }`. It calls `stop` on 0→1 and `start` on 1→0, and never goes below 0.
- `mail.js`:
  - `validate({ name, email, msg }) → { name: bool, email: bool, msg: bool }` (true means it has a problem; the email must match `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`);
  - `composeMail({ name, email, msg, topic }, to) → { subject, body, href, text }`. The subject is `${topic || 'Project'}: ${name}`. The body is `msg\n\nname\nemail`. The href is `mailto:` with both parts `encodeURIComponent`-encoded. The text is `To: …\nSubject: …\n\n…`.

  - `fadeFor(false, 200) === 0.5`; `fadeFor(true, 9) === 0.016`.
