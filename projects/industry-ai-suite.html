Independent engineering project · October 13, 2026

Industry AI Suite

Ten local review tools with source receipts, optional cited drafting and a durable human review flow.

What it does

The suite handles bounded reviews across finance, research, support, operations and security. Each processor produces findings, provenance, uncertainty and a human next step. Permitted organization imports stay on the local machine.

Review to receipt

Users can save a minimized receipt, mark it reviewed or request changes, then export or delete it. Private atomic storage retains findings and provenance while omitting raw imports and work-item rows.

Local model drafting

An optional loopback model sees minimized processor findings and allowed evidence IDs. Invalid citations or an unavailable model block drafting without generating a replacement answer or using a cloud fallback. The deterministic review can finish on its own.

Try it

Follow the repository quickstart for the local workbench. The hosted lab retains ten dated recorded journeys; it is a replay of earlier runs.

Verification and limits

The October 13 run passed 382 Python tests, 178 subtests and 19 browser navigation tests. The actual loopback model endpoint was unavailable during this run. Source authority and full organization outcomes remain UNVERIFIED in each receipt. The 2026-09-26 model witness remains dated historical evidence.
