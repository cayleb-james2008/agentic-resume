Independent engineering project · October 13, 2026

Asmodeus

The next version of EvoHedge: a private research tool that tests trading ideas on real past market data.

Research path

It can use an AI model on the same computer, no cloud account needed. Past data must match the market and time period asked for; if real history is missing, the run stops. It never makes up prices.

Paper replay

It replays past prices in order, with fees. If a run restarts, it picks up where it left off without counting a trade twice. Practice, check and final-test periods stay in time order, so tests never peek at the future. Rejected ideas are recorded for review.

Verification

1,107 automated tests passed, covering past-data checks, restarts, fees and clean shutdowns. 20 more tests confirm the local AI connection can't be redirected elsewhere. Installing on Windows and live AI answers are still unverified.

Scope

Private code. Research and paper simulation only: no real-money trading and no performance claims.

Evidence

Private code. Test records kept. No live trading. No performance claims.
