Independent engineering project · October 13, 2026

Asmodeus

The successor to EvoHedge: a private research and paper replay system with explicit data provenance and chronological evaluation.

Research path

The builder admits a configured loopback model without requiring a cloud key. Historical data must match the requested instrument and timeframe; missing real history stops the run rather than substituting synthetic prices.

Paper replay

Paper runs replay historical bars chronologically with persisted cursors and fees. Restarting a run preserves its place and prevents duplicate fills. Train, validation and test slices stay in time order, with refutation records available for review.

Verification

The merged implementation passed Windows CI with 1,111 Rust workspace tests, formatting, Clippy, documentation, the unchanged coverage gate and 33 Python tests. Linux tests and parity checks also passed. The transport tests confirm that keyless local requests ignore proxy settings and refuse redirects. Native installation and live model inference remain unverified.

Scope

The source remains private. This project covers research and paper simulation; live money trading and investment-performance claims are outside its scope.

Evidence

Private source. The tested implementation is merged; no live trading, live model or performance claim is made.
