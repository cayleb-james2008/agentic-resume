Independent engineering project · October 13, 2026

Ergon

A delivered Windows employee-assistant installer with native Outis taskbar management, ticket-driven connector builds and device-scoped screen tools.

Built around the employee

Ergon installs an OpenClaw workspace designed to preserve employee data through upgrades. The assistant supports a lightweight default route with optional expert consultation; live model calls remain unverified. Outis provides a neutral taskbar interface for setup, support requests and connection status.

Screen-based remote maintenance

Reviewed tickets use durable storage, immutable retries and fenced repair leases. Each maintenance worker is bound to one Windows device, with PowerShell, diagnostics, power/reconnect tools and a real remote Desktop canvas. PNG image tool results support screen inspection, mouse and keyboard input; further actions invalidate prior visual evidence.

Automatic connector builds

A ticket queues a separate builder that reads public API documentation, generates a declarative REST manifest and tests the trusted template. The connector grant names exact read/write operations; account credentials are entered through protected Windows setup. Activation and rollback require a local Gateway reload and tool-registry check.

Phone and workflow integration

Reviewed onboarding turns an approved work example into a versioned assistant workflow, with separate activation and rollback. Hosted voice workflows require exact operator approval and share a budget with model calls. Contacts and provider settings stay in protected local configuration.

Verification

Verification: 496 Node tests, 80 Python tests and three headless Chromium fixtures passed. The fixtures exercised the pinned Mesh canvas, pointer and keyboard input, screenshot delivery and reconnect; seven Windows helpers compiled against pinned .NET Framework references.

Current pilot status

The 1.4.9 installer has been delivered on the pilot USB. Protected Outis and MeshCentral endpoints passed strict public HTTPS checks. Windows installation, enrollment, actual screen control and reboot recovery are under live checks; no hosted event worker, live model or connector-account call, or phone test has been completed.
