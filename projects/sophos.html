Sophos

A Windows desktop port of Prime Intellect's open-source Prime Agent, presented with the upstream runtime credit intact.

  • Windows 10 / 11
  • Tauri 2 + Rust
  • Node bridge + React UI
  • Prime Agent upstream

What it does

Sophos packages Prime Intellect's open-source coding agent as a Windows desktop app. Its public README describes a Tauri 2 shell, Node bridge sidecar, and React frontend; the upstream daemon performs the agent work.

How to try it

Follow the repository's Quick Start and download instructions. The public release page currently lists Sophos v0.6.0 (Beta), released 2026-08-16, with a Windows x64 installer. Review its beta note and release details before installing; this portfolio has not run the installer.

The agent can call tools, edit files, and run shell commands. Use a disposable workspace and review permissions before trying it.

Source proof

October 2026 candidate verification: at revision ad168c7 of open draft PR #10, two native Windows CI runs passed eight UI suites: 57 case results without skip markers and two skipped interaction branches. Inbox read-state and theme/profile persistence after restart were exercised over demo IPC, not live provider inference. Read the push run and pull-request run.

The separate open draft PR #9 baseline passed 1,122 frontend tests and 47 Windows named-pipe checks, with native-module loading and guarded MSI packaging. These candidate results do not validate the older released installer or the newer dependency-hardening branch, whose Windows acceptance remains pending.

The public repository and README document the Windows port, architecture, quick start, and screenshots. The repository links to the original Prime Intellect Prime Agent source.
