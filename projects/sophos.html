Sophos

Coding-agent desktop. Real session profiles and local model catalogs, wired to the daemon.

Profile to session

A chosen profile supplies its system prompt to a real daemon session. The UI separates live prompt changes from safety or tool-policy hints the daemon does not enforce.

Local model setup

Find or register a loopback model endpoint. Its catalog goes to the daemon. Provider changes keep settings on failure and leave other config alone.

Verification

October 13: 1,213 UI tests, 81 Node tests, TypeScript checks, lint, production builds: pass. Isolated daemon run: catalog registration, durable sessions, restart recovery verified. App audit clear. The bundled runtime keeps two extract-zip advisories in its disabled ZIP helper.

Acceptance boundaries
