## Methods to nest (board-wide)

### 1. Hero Frame First (mandatory)
Perfect the still (lighting, composition, bandit mark/character) **before** animation. Image-to-video is the contract; text-to-video improvises brand away.
VERIFIED — official Cinema Studio guide.

### 2. Build the rig like a DP
Lock sensor/camera profile, lens character (e.g. Cooke), focal length (8–50mm range in Studio), aperture/DoF — then prompt subject/light.
VERIFIED — official guide “Phase 1: Build the Rig”.

### 3. Shot-based pipeline
Script → shot list → references → generate per shot → pick takes → finish in editor (sound/grade). Portfolio reel = short film, not one lucky clip.
VERIFIED — studio scale article + practitioners.

### 4. Cinema vocabulary > mood words
Specify shot size, lens, light direction, camera move (dolly/orbit/truck/pan/tilt/zoom, POV, robot arm, helicopter in 4.0). Mood adjectives decorate; optics steer.
VERIFIED — official motion controls + Open Your AIs tutorial.

### 5. Director’s Panel / look lock (Cinema Studio 4.0)
One surface for genre, era, tempo (Single Shot → Chaotic), camera, lens, aperture, moves, 50+ color palettes, lighting presets/custom.
Default start: **4.0** for deepest control, ≤50 refs, clips ≤30s (Seedance 2.5).
Use 3.5 if AI Director chat / team Elements sharing; 3.0 for physics-weight motion.
VERIFIED — official help center (2026-09-01).

### 6. Elements / Soul Cast for bandit consistency
Create reusable Elements: bandit character/mark, locations, props. Soul Cast actors → Save to Elements; reuse across shots/projects so identity doesn’t drift.
VERIFIED — official FAQ “How do I keep characters and locations consistent”.

### 7. Grid + 3D scene before commit
Grid 2x2/3x3/4x4 to storyboard; optional 3D scene explore for angle — then animate.
VERIFIED — Cinema Studio 2.0 guide.

### 8. Multi-shot with intent
Up to 6 shots in Studio 2.0 family (1–12s/shot, max ~12s total @1080p in that guide); 4.0 extends longer clips (≤30s). Manual mode: duration + move + speed ramp per shot. Genre biases pacing.
VERIFIED — official guide + help.

### 9. Model routing by job
Pick model/version for the shot (choreography vs contact/physics vs still plate). One-model-everywhere is amateur.
VERIFIED — practitioner (Open Your AIs).

### 10. Inspect failure modes → finish outside
Hands, faces, text, reflections, geometry. Native audio exists (2.5–4.0) but portfolio hero may still want muted loop + separate grade.
VERIFIED — help (native audio) + practitioners (finish in editor).
