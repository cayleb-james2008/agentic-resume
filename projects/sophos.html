Sophos

A public Windows coding-agent project documented as a port of Prime Intellect's open-source Prime Agent.

Problem

Most coding-agent demos assume a Unix-first world. Windows workflows still need an agent that respects the platform instead of papering over it.

Role

The public README credits Prime Intellect for the upstream agent runtime, daemon, and bridge. This case study makes no sole-author or employment claim.

Craft

The repository documents a Windows workspace with a Tauri shell, Node bridge sidecar, and React frontend, and keeps the upstream credit boundary explicit.

Outcome

The public Sophos repository demonstrates a Windows port of Prime Intellect's open-source agent; no product-launch or production-use claim is made.
