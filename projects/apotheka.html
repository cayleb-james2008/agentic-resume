Static lookbook

apotheka-site

A static lookbook site — presented honestly as static craft, not a dynamic product platform.

Problem

Brand and merch narratives often get overbuilt into “platforms.” The need here was a sharp static lookbook that ships without pretending to be a commerce engine.

Role

Builder of the static lookbook experience — layout, type, and honest framing as a lookbook.

Craft

Kept the stack static on purpose: editorial pages, restrained motion if any, no fake dynamic inventory. Visual hierarchy carries the brand without gadget density.

Outcome

A public static lookbook that reads as finished craft. Explicitly not claimed as a dynamic product platform.
