# Art direction — Y2K / cyberpunk / anime (frozen for this pass)
Date: 2026-09-22

## Vibe
Grungier Catppuccin Mocha purple. NOT soft kawaii latte. Think early-2000s web + Ghost in the Shell + dirty CRT: chromatic aberration, halftone, scanlines, scratched metal, sticky gel buttons sticky-chrome, Japanese street signage glyphs as texture (not readable logos), compressed JPEG artifacts used on purpose.

## Palette
Keep Catppuccin Mocha bases (#11111b, #1e1e2e) with mauve #cba6f7 / lavender #b4befe / pink #f5c2e7 / red #f38ba8. Add grit overlays, noise, RGB split.

## Character
Espresso-cup / mocha mascot reinvented as cyberpunk anime: sharper, slightly menacing-cute, chrome accents, sticker-sheet wear, glitch eyes. Same character must appear in hero video, logo lockups, and project showcases for consistency.

## Motion
anime.js for hero entrance, demo panel mounts, mascot stickers, CTA micro-interactions. Prefer one UI kit vocabulary (Shoelace or Pico-like primitives) — do not invent parallel button systems.

## Video
Hero reel and all stills/logos must match this direction. When Cayleb supplies model-generated MP4, regenerate stills/mascot to match that clip’s look.
