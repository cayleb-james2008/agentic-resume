ChainWatch

Review supplied EVM address observations against a rate baseline and flag anomalies for a person. The local path cannot sign or transfer.

  • Local EVM input
  • Watch-only alerts
  • No wallet access
  • Human escalation

What it does

The local workbench accepts permitted EVM observations in CSV or JSON. It checks Base or Ethereum addresses, compares rates with a supplied baseline, marks short sampling windows as uncertain, and sends threshold breaches to a human review queue. The importer asks the user to assert authorization; the organization must still verify it.

Hosted example and source scope

The recorded lab uses two invented observations to show the calculation. It makes no chain request and contains no company address. The local processor is working, but no external EVM feed or company exposure result is connected.

For organization use: the responsible owner must confirm the address, sampling history, source rights, and escalation authority before treating an alert as real.
