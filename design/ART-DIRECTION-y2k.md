# Art direction — Y2K / cyberpunk / anime (frozen for this pass)
Date: 2026-09-22 (updated: cyber-nomad character)

## Vibe
Grungier Catppuccin Mocha purple. NOT soft kawaii latte. Think early-2000s web + Ghost in the Shell + dirty CRT: chromatic aberration, halftone, scanlines, scratched metal, sticky gel buttons, Japanese street signage glyphs as texture (not readable logos), compressed JPEG artifacts used on purpose.

## Palette
Keep Catppuccin Mocha bases (#11111b, #1e1e2e) with mauve #cba6f7 / lavender #b4befe / pink #f5c2e7 / red #f38ba8. Add grit overlays, noise, RGB split.

## Character
**Cyber-nomad** — hooded wanderer, tactical pack, handheld terminal, glowing eyes, sticker-sheet wear, glitch grit. Asset: `assets/img/y2k/mascot-cyber-nomad.png` (also `assets/img/stickers/mascot.png`).
**Do not use coffee-cup / espresso mascot imagery.**

Same character appears in hero CRT overlay, dock brand mark, and contact boot panel.

## Motion
anime.js for hero entrance, demo panel mounts, mascot stickers, CTA micro-interactions. Prefer one UI kit vocabulary (Shoelace) — do not invent parallel button systems.
