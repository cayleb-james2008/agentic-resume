Independent engineering project · October 13, 2026

Sophos

A coding-agent desktop connecting real session profiles and local model catalogs to the daemon.

Profile to session

A selected profile now supplies its system prompt when creating a real daemon session. The interface distinguishes these live prompt changes from safety or tool-policy hints that the daemon does not enforce.

Local model setup

Users can discover or register a loopback model endpoint and make its catalog available to the daemon. Provider changes preserve settings on failure and protect unrelated configuration.

Verification

The October 13 implementation passed 1,213 UI tests, 81 Node tests, TypeScript checks, linting and production builds. An isolated daemon run verified catalog registration, durable sessions and restart recovery. The application audit is clear; the bundled runtime retains two extract-zip advisories in its disabled ZIP helper.

Acceptance boundaries

The GitLab and GitHub histories are reconciled in the reviewed implementation branch. Native Windows installation and real model inference remain separate checks.

Attribution

Sophos integrates an existing coding-agent runtime. The independent work covers the desktop interface, profile delivery, provider configuration, lifecycle behavior and build provenance.

Evidence

Public Sophos mirror and implementation PR #20. Current source verification is dated October 13; older CI runs remain historical evidence.
