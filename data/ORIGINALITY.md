# PFV-100 — originality note

The PFV-100 / PFV-150 / PFV-200 "precision flow valve" family in this folder is
**entirely fictional and original**, created as demo data for the PDM Forge
vault simulator. It contains:

- No real Lee Company CAD, drawings, part numbers, or products.
- No copied geometry — the `.sldprt` paths are vault-simulator records, not
  real SolidWorks files.
- A demo designer identity ("C. Forge") that is not a real person.

Verified by inspection 2026-09-17: every part number, description, and revision
in `parts.json` was typed for this demo. Real CAD geometry arrives in P2 via
Linux-native rebuilds, still 100% original.
