at a glance

What dotz does

dotz is a Rust and Tauri coding dashboard for agent sessions, workflow graphs, persistent projects and local memory. The agent engine lives inside the app rather than in a separate process, so the graph, the tools and the session share one state. The lead can delegate to subagents, and every subagent appears as a node with its tool calls streamed onto it.

Profiles and slash-command presets request different strategies: sequential chains, review, parallel dispatch, or direct work by one agent. The graph records what ran; it does not certify a reviewer's verdict, and the repository says to inspect the changes and the project checks before accepting a result.

Verified implementation and limits

Reviewed source is merged to the main branch, and six hosted jobs passed on that head: 839 Rust tests on Linux, 828 on Windows and 831 on macOS, plus formatting, code-quality, cold-start install policy and dependency checks. This page records that the merged implementation and the tested head match.

Those jobs do not cover everything. A signed installer from the source head, the updater install-and-relaunch path, and live provider inference still need separate acceptance. The tag-triggered release workflow creates a draft; a passing build alone does not verify those journeys. This page repeats those boundaries rather than rounding them up.

what is not verified

  • A signed installer from the source head, the updater path and live provider inference are not covered by the test counts.
  • A passing build alone does not verify those journeys; the repository says so explicitly.
  • The graph shows what ran, not whether a person approved the result.
  • macOS and Windows coverage is by hosted jobs, not by a full-app install on each system.
