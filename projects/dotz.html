Independent engineering project · Rust · Tauri

dotz

A desktop app that runs and supervises AI coding agents.

What it does

It connects the app to the agent, lets you pick which AI to use, and runs tools under supervision. Background programs and shutdowns stay visible.

Local routing

If you choose an AI on your own computer and it fails, the app says so clearly instead of quietly switching. Cleanup waits until background programs have really closed.

Verification

Core automated tests pass on Linux (839), macOS (831) and Windows (828), along with formatting and code-quality checks across all 6 hosted check jobs. A clean install and the full app on each system are still separate checks.

Source proof

See the public code and the merged implementation. Earlier work and history are kept.

Evidence

Automated checks are recorded. The full app on each system is checked separately.
