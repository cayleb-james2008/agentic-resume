Independent engineering project · October 13, 2026

Ergon

A Windows installer that gives each employee their own AI assistant, plus a support desk that can fix things remotely.

Built around the employee

Each employee gets their own assistant workspace, and their data stays put through updates. A small taskbar app, Outis, handles setup, help requests and connection status.

Screen-based remote maintenance

Support works from reviewed tickets. Each repair helper is tied to one computer. It can run diagnostics, restart or reconnect the machine, and see and control the screen when needed. Every new action needs a fresh look at the screen.

Automatic connector builds

A ticket can ask for a new app connection. A builder reads the app's public documentation, makes the connection and tests it. Employees approve exactly what it may read or change, and sign in through protected Windows setup. Turning a connection on or off is checked before it takes effect.

Phone and workflow integration

An approved example of someone's work becomes a saved routine they can switch on or off. Phone calls need an operator's exact approval and share the AI's spending limit. Contacts and settings stay protected on the local machine.

Verification

539 Node tests, 80 Python tests and 3 publisher checks pass, covering keeping each computer separate, repair time limits, connection permissions, retries, interrupted installs and the support service. A real browser test checks screenshots, mouse and keyboard, and reconnecting. All 8 Windows helpers build cleanly.

Pilot acceptance

I delivered the 1.4.9 installer on the pilot USB. Protected Outis and MeshCentral endpoints returned HTTPS 200; unauthenticated ticket access returned 401. The 1.5.0 source defaults native memory to Hindsight and includes signed updates that apply on close. Its installer is built and the protected update feed is live; I verified the update signature and downloaded the full installer over HTTPS. Linux Hindsight isn't provisioned while model selection is pending, so I haven't tested live memory retrieval. Windows installation, enrollment, actual screen control, reboot recovery and live connector use still need live checks. Hosted Work automation, repair jobs, model calls and phone or voice tests haven't been verified.
