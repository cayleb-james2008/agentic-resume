at a glance

What it reviews

PipelineRelay checks the public details of one selected GitHub repository and prepares a public-research note. The default is pytest-dev/pytest. To select another repository, pass both safe path segments; both values must be supplied together.

The note records the repository name, default branch, update time with its age, the returned license name and terms address, and a response hash. The app reads no project readme, issue, advisory, or contact text.

Where a person takes over

A reviewer confirms the repository identity, license, and relevance for an authorized public-research question. There is no outreach step.

Public repository details are not a private account record, a lead, consent, or permission to contact anyone. The full sales handoff stays unverified until an authorized account source, consent evidence, and an accountable owner exist.

what is not verified

  • Public repository details only; no account records, contact details, or consent were read.
  • No outreach, message, or contact capability exists.
  • The full sales handoff stays unverified until authorized account data and consent evidence exist.
  • The shared ten-workflow runner still needs a separate update before it can pass a chosen repository through its own screen.
