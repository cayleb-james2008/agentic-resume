# "Sign-off" Homepage Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. All steps below are done on branch `claude/amazing-bohr-tiwtka`.

**Goal:** Remake the whole site in one new look for two readers: frontier-tech hiring managers and team owners who want AI. The hero gets two doors and a live Ask bar; the project pages, résumé page, lab, 404 and share card follow.

**Architecture:**
- **Unchanged pipeline.** Python templates in `scripts/home/templates/` render each section from `site/content.json` and `resume/resume-content.json`, with plain CSS per section in `site/css/`.
- **Scripts.** Vanilla ES modules: `site/js/ask/` (a pure matcher, the stream timing and the mount), `site/js/home/` (overlays, mail, the Ergon graph, the work preview) and `site/js/engine/` (the ticker, env).
- **Boot.** `site/js/main.js` mounts the overlays, then Ask, the work index, Ergon and the page's clicks.

**Tech stack:** Python 3 templates, vanilla ES modules, the vendored Mona Sans variable font, Pillow (share card), node:test, Python unittest, Playwright with Chromium at `/opt/pw-browsers` (QA only).

**Spec:** `docs/superpowers/specs/2026-10-16-sign-off-design.md`

## Global constraints

- **Claim tests stay verbatim.** Every claim and copy guardrail test is unchanged: `candidate-resume`, `recruiter-*`, `hosted-lab-uncertainty` and `home-worth` byte for byte, plus the claim rules inside `home-content`, `home-guide`, `home-few-words` and `home-resume-half`.
- **New copy obeys the rules.** Numbers come only from the résumé ($100 aside). No jargon. "pilot" appears once in the guide. No "return", "client", "customer", "revenue" or "profit".
- **Hidden states only under `.js:not(.reveal-failsafe)`.** No keyframes. Hover only under a fine pointer.
- **No third-party request at runtime.** No script makes a network request.
- **Commit trailer:** `Co-Authored-By` and `Claude-Session` lines as given for this session.
