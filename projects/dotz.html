Flagship · multi-agent dashboard · axum + Tauri

dotz

A local-first control surface for coordinating coding agents — honest scope, no invented SaaS users.

Problem

Running multiple coding agents without a coherent dashboard becomes chaos: opaque status, duplicated work, and no shared control plane for humans in the loop.

Role

The public repository documents a multi-agent coding dashboard spanning an axum API and a Tauri desktop shell; its commit history does not establish sole authorship.

Craft

The project presents agent and run surfaces as an editorial control plane, with clear status, planner/worker separation, and a quiet dark UI. Its public stack (axum + Tauri) is local-first.

Outcome

The public repository demonstrates a local-first multi-agent coding dashboard. No production-SaaS user, adoption, or sole-author claim is made.
