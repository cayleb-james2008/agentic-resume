Independent engineering project · Rust · Tauri

dotz

A coding-agent desktop with explicit local routing, supervised tools and platform-aware process cleanup.

What it does

dotz connects the desktop interface to an agent core, provider selection and supervised tool execution. Lifecycle policy keeps child processes and session shutdown visible.

Local routing

Local-provider errors stay on the selected route and show an actionable status. Cleanup retries retain session state until child processes have actually closed.

Verification

The reviewed implementation passed all six hosted CI jobs: 839 core tests on Linux, 828 on Windows and 831 on macOS, plus formatting, Clippy and dependency-policy checks. Clean-download installation, native UI acceptance, signing, updater and live-provider checks remain separate.

Source

Public repository; the reviewed implementation is merged at 4df6871.

Evidence

CI verifies the core and focused process fixes. It does not establish a clean installer, native UI, signed updater or live provider use.
